(CC BY-SA 4.0)**:

> https://creativecommons.org/licenses/by-sa/4.0/

## Why this license

`content/` is a curated merge of several upstream sources, each already under
some flavor of attribution + share-alike license (see `ATTRIBUTION.md` for
the exact terms and links). CC BY-SA 4.0 is compatible with all of them and
is the strictest of the group, so licensing the merged result under it keeps
every upstream source's terms satisfied without having to track which rows
came from where. In short: if you reuse `content/`, credit this project and
the sources listed in `ATTRIBUTION.md`, and release any adapted version
under the same or a compatible license.

## What this does NOT cover

- Code under `tooling/` and `style/` is MIT-licensed — see `LICENSE`.
- Lexin-sourced audio (see `ATTRIBUTION.md`) is included under its publisher's
  own "open access" terms, not CC BY-SA, since no explicit license is stated
  for it. If you are the rights holder and want it removed, open an issue and
  it will be taken down promptly.
